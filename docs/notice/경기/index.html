경기도 공고는 해당 지역 거주기간(공고마다 다름)을 채운 사람이 먼저 공급받는 경우가 많아요. 거주 요건과 물량 배분은 공고별 페이지의 '자격 요약'에서 공고문 원문 문장과 함께 확인할 수 있어요.

각 공고 페이지에는 일정, 주택형별 분양가와 추정 시세, 계약금 예시, 특별공급 물량, 마감 공고의 경쟁률·당첨 가점을 정리했어요.
