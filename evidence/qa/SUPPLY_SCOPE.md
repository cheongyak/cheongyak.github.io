# 공급유형 정확성 · 판정 범위 · 과신 방지 (2026-10-02 사용자 QA 피드백)

## 1. 분석 (구현 전)

### 데이터 흐름과 공급유형이 지나가는 곳
```
청약홈 OpenAPI (APT 분양정보 · 무순위/잔여세대 · 경쟁률) — HOUSE_SECD(01 APT·04 무순위·06 계약취소·10 신혼희망타운), HOUSE_DTL_SECD_NM(국민/민영), RENT_SECD_NM(분양주택/분양전환 가능임대/…)
 → app/sources/applyhome.normalize : kind·house_secd·house_dtl·rent_secd 를 그대로 보존
 → app/pipeline.build_listing : category(general/remainder) · rental = is_rental(raw) (RENT_SECD_NM 우선, 없으면 공고명)
 → app/notice_pdf.parse_notice : 공고문에서 규칙(소득·자산 표 pub_limits, 거주·통장·특공 표 …)
 → docs/listings.json (rental, rent_secd, house_dtl, category, pub_limits …) · docs/archive/past.json (rent_secd 보존)
 → 화면 fromApi → isRental(L) · eligibility · spJudge · eligBucket → 카드·상세·필터·지난 공고
```
- 수집하는 원천은 청약홈 **APT 분양정보**와 **무순위/잔여세대**뿐이다. 행복주택·국민임대·통합공공임대 같은 LH 임대 모집은 이 API 에 없다(LH청약플러스·마이홈) — 지금은 들어오지 않는다.
- 2026년 데이터(지금 192 + 보관 2,092 주택형)의 임대: **2개 공고 16주택형(0.7%)**, 모두 RENT_SECD_NM '분양전환 가능임대'.
  - 2026000307 군포대야미 A-1 **6년 분양전환공공임대**(LH, 4주택형)
  - 2025000645 이천 **5년 공공건설임대(민간, 카사펠리스) 임차인모집**(12주택형)

### QA 지적 사례의 실제 상태 (보고서 요약이 아니라 코드·데이터로 확인)
| 공고 | 분류 (수집) | 화면 표시 | 판정 (고치기 전) |
|---|---|---|---|
| 2026000307 | rental=true (RENT_SECD_NM) — v1.40.0 부터 | '공공임대' 배지, 금액 '임대보증금', 시세 차익 없음 | 일반공급: 공고문 소득·총자산 표(<표4>·<표2>·<표3>)로 판정, 특별공급: 공고문 유형별 표(v1.42.0). 블라인드 감사·판정 사례 49건 일치 |
| 2025000645 | rental=true (RENT_SECD_NM, 공고명 '임차인모집'도) | '공공임대' 배지 | 공고일 2026-02-20 이 규칙 개정(2026-06-15) 전이라 지난 공고 판정 대상 밖. **같은 유형이 지금 공고로 오면**: 자격표를 못 읽어 296개 조건 중 '확인 필요' 265 · **'불가' 31**(분양 규칙의 무주택·거주·통장 결과로 확정) · '가능' 0 |

→ '임대 → 분양' 오분류는 v1.40.0 에서 이미 고쳐졌고 지금 데이터에는 없다. 남은 위험은 구조였다:
1. **'가능'이 안 나오는 이유가 우연**: 임대인데 자격표를 못 읽으면 '소득·총자산 (공공임대) 확인 필요' 항목 하나 때문에 '가능'이 안 될 뿐, '판정하지 않는다'는 규칙이 코드에 없었다. 그 항목이 빠지는 경로(면적 조건·스위치)가 생기면 분양 규칙만으로 '가능'이 된다.
2. **분양 규칙의 '불가'를 임대에 확정으로 씀**: 31건 '불가'는 분양 규칙(국민주택 1순위·거주지) 결과다. 임대 공고 자격으로 확인한 결론이 아니다.
3. **무순위(이름만으로 임대 판별)** 이름 목록에 행복주택·국민임대·통합공공임대·장기전세·민간임대 등이 없었다.
4. **과신·경계값 검사가 사례 중심**: 판정 사례 349건은 정해 둔 경계만 본다. '모르는 것이 늘었는데 가능이 되는' 경우, 경계 앞뒤에서 결과가 되돌아가는 경우를 실제 공고 전체에서 찾는 검사가 없었다.
5. 판정 지원 범위를 사용자에게 말하는 방식이 없었다 — '확인 필요' 문구가 '아래에서 답하면 판정돼요'로 나와, 답해도 판정되지 않는 공고에도 같은 안내.

## 2. 개선 (구현)

| 무엇 | 어떻게 | 스위치 |
|---|---|---|
| 판정 지원 범위 `judgeScope(L)` | full / partial / none 과 이유. **none**: 임대인데 자격표(pub_limits total)를 못 읽음 · 일반공급인데 국민/민영 구분 없음 · 지원 밖 공급 구분. none 이면 분양 규칙의 '충족·불가'를 확정으로 쓰지 않고 맨 위에 '판정 범위' 항목(확인 필요) → 결과는 언제나 '확인 필요', 특별공급도 '확인 필요'. 카드 '판정하지 않는 공고 · 모집공고문 신청자격 확인', 상세 맨 위 '이 공고는 판정하지 않아요 — 이유', 체크리스트 '분양 기준으로 보면 맞는 조건 (참고 · 이 공고 판정 아님)'. **partial**: 공고문 표를 읽은 공공임대(2026000307형) | `judge_scope` |
